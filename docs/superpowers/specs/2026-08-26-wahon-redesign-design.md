# 和本UIリデザイン 設計

- 日付: 2026-08-26
- 対象: 思考整理（voice-memo PWA）
- 状態: 設計確定待ち

## 背景と目的

現行UIは真っ黒の背景にネオンカラー、ゲーム要素（レベル・XP・モンスター・バッジ）が強く出ている。利用者が「未来感」の3案と「古書」の3案を比較したうえで、**和本（和綴じ）** の方向を選択した。

- 用語も**全部和風**に置き換える
- ゲーム要素は**薄める**（削除ではなく非表示にし、localStorageのデータは温存）

段階を分けて実装する。一度に変えると差が大きすぎて元に戻りにくいため、CSS→文言→装飾の3段階に分ける。

## デザイントークン

すべてCSS変数で管理し、単一の`:root`で定義する。**`prefers-color-scheme: dark`は無視**（和紙の色調を守るため常にライトで描画する）。

| 用途 | トークン | 値 |
|---|---|---|
| 紙色（背景） | `--wa-paper` | `#ede4d0`（生成りの和紙） |
| 紙色2（カード裏） | `--wa-paper-2` | `#f5eed8` |
| 墨色（本文・見出し） | `--wa-sumi` | `#241d18` |
| 淡墨（副次） | `--wa-sumi-2` | `#6a5a48` |
| 朱（アクセント） | `--wa-shu` | `#a83a2a` |
| 罫線（濃） | `--wa-line` | `#2d251c` |
| 罫線（淡） | `--wa-line-2` | `rgba(30,20,15,0.2)` |
| 影 | `--wa-shadow` | `rgba(60,40,22,0.15)` |

現行の `--accent`、`--accent2`、`--surface-1`、`--text-1` などのトークンは残したまま、上記の和本トークンを新設して**主要な塗りを差し替える**。既存トークンを残す理由は、モンスター図鑑など「非表示」にする要素のCSSを消さずに済むため（表示だけ隠す）。

## タイポグラフィ

Google Fontsから読み込む（すべて無料・現行で `Inter` と `Noto Sans JP` を読んでいる箇所を差し替える）。

| ロール | 書体 | 用途 |
|---|---|---|
| 題字・見出し | Shippori Mincho（600/700） | ヘッダー題字、カード見出し、朱印 |
| 本文 | Klee One（400/600） | メモ本文、日記、リスト項目 |
| 副次・補助 | Noto Serif JP（400/500） | ラベル、メタ情報、フォールバック |

現行の `Inter, Noto Sans JP` の `font-family` 指定は全部 `'Shippori Mincho', 'Noto Serif JP', serif` に置き換える。本文は `'Klee One', 'Noto Serif JP', serif`。

## ゲーム要素の扱い

**「削除」ではなく「非表示」にする**。CSS で `display: none` を当てるだけ。localStorageの `voiceMemoGame.v1` は残す。将来復活させたくなったら1行外すだけで戻せる。

| 要素 | 具体的な処理 |
|---|---|
| ヘッダーの `Lv.4 タスク職人 🔥3` | `#gameStats` を `display: none` |
| ボスカード（討伐対象モンスター） | `#bossCard` を `display: none` |
| 相棒モンスター | `#companionCard` を `display: none` |
| 討伐記録 | `#defeatedToday` を `display: none` |
| ボス撃破の紙吹雪・演出 | 演出関数はそのまま残すが、CSS で `.confetti-p`, `.xp-popup`, `.combo-popup`, `.gacha-popup`, `.levelup-overlay` を `display: none` |
| モンスター図鑑（設定） | `#monsterDexSection` を `display: none` |
| 活動カレンダー（設定） | `#calendarSection` を `display: none` |
| 実績バッジ（設定） | `#badgesSection` を `display: none` |
| テーマ（着せ替え）（設定） | `#themeSection` を `display: none` |
| ゲーム設定（効果音・バイブ・通知） | `#gameSettings` は残す（機能設定のため。文言だけ和風に） |
| デイリーミッション | 表示継続、文言変更 |
| 今日のフォーカス | 表示継続、文言変更 |
| 今日のクエスト（集中タブ） | 表示継続、「今日の務め」に翻訳 |
| ポモドーロ | 表示継続、「静坐」に翻訳 |
| BGM選択（ホワイトノイズ・雨音・焚き火） | 表示継続、「無・風・雨・炉火」に翻訳 |

内部でスコア加算やレベルアップ判定を行う関数（`onTaskComplete`, `showXpPopup`, `attackEnemy` など）はすべて残す。localStorageも触らない。**見えなくなるだけで裏で動き続ける**。

## 装飾要素

**縦書きの題字と朱印を各タブの上部に配置する**（先ほど承認されたモックアップと同じ形）。

- 上部ヘッダー: 題字（例:「録音」）＋副題（例:「思考整理・壱之巻」）＋朱印（1文字）
- 綴じ糸: 画面左端に縦の点線（`repeating-linear-gradient`）
- カード枠: 二重罫（外枠＋内枠のインセット）
- 下ナビ: アクティブなタブだけ朱印風（朱の背景に紙色で漢字）

これらは第3段で追加する。第1段では**下地となる色・書体・カード枠**まで。

## 段階的な進め方

3つの計画に分ける。それぞれ独立してデプロイでき、各段階の間で実機確認できる。

### 第1段（v59） — 下地
- グローバルCSSの色・書体を和本トークンに差し替える
- カード（`.glass-card` など）の枠を和本の二重罫に
- 下ナビの背景・文字色を和本に
- **この時点で見た目は和本になるが、文言は今のまま**（英字・現代語まじり）

### 第2段（v60） — 文言とゲーム要素
- 全用語を和風に置き換え（`public/index.html` と `public/app.js` の描画箇所）
- ゲーム要素の該当DOM を `display: none`
- 演出（紙吹雪・XPポップアップ）を CSS で非表示
- **この時点で用語も画面から見えるゲーム要素も和本らしくなる**

### 第3段（v61） — 装飾
- 各タブ上部に縦書き題字＋朱印
- 綴じ糸の縦罫
- カード枠の二重罫の細部調整
- 下ナビの朱印風アクティブ表示

各段階で `/api/health` のバージョンを上げる（v59, v60, v61）。

## 検証方法

自動テストは置かない（既存タスクと同じ方針）。各段階で以下をブラウザ実機（Android想定・375px）で確認する。

**第1段**:
1. 全8タブが正常に描画される（クラッシュしない）
2. 背景が和紙色、本文が墨色、フォントが明朝体になっている
3. 既存機能（録音・保存・整理）が動く
4. ゲーム要素（Lv.4、モンスター）は**まだ表示されている**（第2段の対象）

**第2段**:
1. ヘッダーの「Lv.4」以下が非表示
2. ボスカード・相棒モンスター・討伐記録が非表示
3. 保存ボタンが「綴じる」、AIでまとめるが「筆入れ」になっている
4. モンスター図鑑・活動カレンダー・バッジ（設定）が非表示
5. 内部のXP加算は動いている（`voiceMemoGame.v1` を見て `xp` が増える）

**第3段**:
1. 各タブ上部に縦書き題字＋朱印が出る
2. 綴じ糸の縦罫が出る
3. 下ナビの現在タブが朱印風になる

## 未確定事項と既定値

| 項目 | 既定 | 変更が必要になる条件 |
|---|---|---|
| ダークテーマ | 対応しない（常にライト） | 暗い場所で読みにくい場合、和本の墨版として別テーマを追加 |
| ゲーム要素の完全削除 | しない（非表示のみ） | 半年使ってみて誰も気にしないなら削除 |
| 数字の漢数字化 | しない（Lv.4は非表示、日付は算用数字） | 「壱・弐・参」を装飾に使う要望が出た場合 |
| 段階間のインターバル | 各段階で実機確認 | 一気に v59〜v61 をまとめて出したい要望が出た場合 |
